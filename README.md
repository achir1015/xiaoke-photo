# 小柯機器人圖像編輯助手

全繁體中文的圖層式影像編輯器。圖層、遮色片、調整圖層、圖層樣式、文字、向量、筆刷與 PSD 都由修改自 PhotoCraft 的引擎提供，
外層加上 OpenAI 繪圖、插件功能、語音動畫教學與自動更新。

系統開發：吳玉柱 先生 與 Claude AI Opus 5.5

## 功能

- **OpenAI 金鑰**：在右上角系統工具設定，金鑰加密存本機。
- **AI 生圖**：文字生成圖像，可選風格、尺寸、數量、透明背景、自動切圖，結果自動加入圖層。
- **AI 修補**：塗抹移除人物、物件、浮水印、文字並補完背景；局部重繪；畫質提升；移除背景；重新打光。
- **人像修圖**：自動磨皮、人像精修、一鍵美顏。
- **摳圖特效**：髮絲摳圖、水波倒影、全景變形、底片調色、黑白暗房、本機打光。
- **降噪放大**：智慧降噪、無損放大。
- **使用教學**：小柯機器人語音加動畫示範。
- **系統更新**：檢查 GitHub Release，自動下載並安裝。

本機插件全部在裝置上運算，不需要金鑰。結果都放在新圖層，不會改動原圖。

## 開發

```bash
npm install
node scripts/fetch-engine.mjs
npm start
```

測試：`npm test`、`node e2e/smoke.mjs`。

引擎修改放在 `engine-patch/`，建置方式見 `engine-patch/README.md`。授權見 [NOTICE.md](NOTICE.md)。
