不用安裝，電腦和平板的瀏覽器都能用（建議 Chrome、Edge 或 Safari）。

主要功能

  • 圖層、遮色片、調整圖層、圖層樣式、文字、向量、筆刷，可開啟與儲存 PSD。
  • 填入 OpenAI 金鑰後可文字生成圖像，移除人物、物件、浮水印並補完背景，結果自動加入圖層。
  • 內建自動磨皮、髮絲摳圖、水波倒影、全景變形、底片調色、黑白暗房、智慧降噪與無損放大，不需要金鑰。
  • 有語音與動畫教學，新版本可在程式內一鍵更新。
